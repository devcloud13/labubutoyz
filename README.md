## 🚀 О проекте

**Labubu Toyz** — полноценный коммерческий интернет-магазин по продаже коллекционных фигурок Labubu (Pop Mart) с бесплатной доставкой по всей России и офлайн-точкой в Санкт-Петербурге.

Проект построен с нуля — от дизайна и вёрстки до настройки CI/CD и подключения веб-аналитики. Охватывает полный цикл онлайн-торговли: витрина товаров, карточки, юридические страницы, FAQ и служба поддержки.

---

## ✨ Функциональность

| Раздел | Описание |
|--------|----------|
| 🛒 **Каталог** | Витрина товаров с карточками, ценами и описаниями |
| 🎁 **Страницы товаров** | Детальные страницы каждой позиции с изображениями |
| 🚚 **Доставка** | Интеграция с CDEK, бесплатно по всей России |
| 📍 **Офлайн-магазин** | Страница физической точки в Санкт-Петербурге |
| ❓ **FAQ** | Ответы на частые вопросы покупателей |
| 📋 **Юридические страницы** | Оферта, политика конфиденциальности, возврат |
| 📊 **Аналитика** | Яндекс.Метрика + Top.Mail.Ru |
